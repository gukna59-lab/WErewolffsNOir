# Инструкция по запуску Telegram-бота "Werewolf Noir"

Этот бот полностью сгенерирован и готов к запуску!
Он работает на Python 3.10+ и библиотеке `aiogram` 3.x.

## Деплой на Render (Автоматически)

Проект содержит файл `render.yaml` (Blueprint), который позволяет развернуть бота на [Render](https://render.com) в пару кликов:
1. Загрузите этот код в ваш репозиторий GitHub.
2. Войдите в Dashboard на Render.com → Нажмите **New** → **Blueprint**.
3. Выберите ваш репозиторий и нажмите **Connect**.
4. Render обнаружит сервис `werewolf-noir` как Background Worker.
5. Заполните переменную окружения `BOT_TOKEN` в панели настроек Render.
> ⚠️ Внимание: на бесплатном тарифе Render хранилище сбрасывается при рестартах, поэтому рекомендуем подключить Disk или внешний PostgreSQL для сохранения профилей или настроить работу с бесплатным диском в платных тарифах.

## Локальный Запуск

### Шаг 1: Скачайте код
Если вы находитесь в AI Studio:
1. Нажмите на меню (три точки) в верхнем правом углу редактора
2. Выберите **"Export to ZIP"** 
3. Распакуйте архив на вашем компьютере.

## Шаг 2: Установка зависимостей
Откройте терминал в папке `werewolf_bot` и выполните команду:
```bash
pip install -r requirements.txt
```

## Шаг 3: Настройка токена
1. Напишите в Telegram боту @BotFather и создайте нового бота
2. Скопируйте полученный токен.
3. Откройте файл `main.py` и вставьте токен в переменную `API_TOKEN` или установите переменную окружения `BOT_TOKEN`.

## Шаг 4: Запуск
В терминале выполните:
```bash
python main.py
```
Бот автоматически создаст базу данных SQLite (`werewolf.db`) и начнет работу. Добавьте его в группу для игры и напишите ему в ЛС команду `/start` для просмотра профиля и магазина.
